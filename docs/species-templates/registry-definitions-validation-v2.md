## 4. The `sessile` open question

**The recommendation is not sound as argued, and no species needs the value.**

The draft's case rests on "Xylum ... moves little or not at all" and "a rooted body that never moves has no key in the ratified nine". Both halves fail against the sources. The ratified design doc assigns Xylum a burrow band of 6-8 (redesign doc line 327), which is a high band for a capability that exists precisely to describe a body moving through solid ground. The species description says it "lives mostly underground as this is where it absorbs its power" — mostly, not always, and living underground is the `burrow` capability by explicit ratified rule (design doc line 301: "Solid isn't a medium - living in rock/sand is the `burrow` capability"). The art shows a bulbous base sitting on open ground with six heavy barbed tendrils, not a plant fused to a substrate. Xylum is a body that travels by burrowing and is borne on more than four tendrils: `multiped` is a fair description of how it is met in the field, not a lie about it.

Sweeping the other 28 for a rooted, fixed body: none qualifies. Terragoyle stands guard "in a statue-like state, hibernating", but it "rises high into the sky" when woken, so it is a flier at rest between flights and a `biped` by the draft's own crouching-humanoid disambiguation; a hibernation posture is a behavior, not a body plan. Neph drifts and is `floating`. Bioflim is `amorphous`. Nothing else in the roster is rooted. So the "a plant-world creature line is expected to have more than one rooted species" argument is a forecast about species that do not exist, and the design doc's own position is that vocabularies are versioned registry data with additive entries (design doc line 301(c) on the media enum, line 135 on registry vocabularies): a tenth body plan can be added later, at zero cost, the first time a genuinely sessile species is authored. Adding it now to serve one species that the ratified doc already says burrows is the more expensive mistake, because every future migration agent then has a tempting tenth key for anything slow.

**Recommended answer to Nick:** decline `sessile` for now. Rule that Xylum is `multiped` with a high `burrow` band, and record the reason (roots bear it and shift it; underground living is `burrow`, not a body plan) so it does not get relitigated. Note in the registry that `sessile` is a reasonable additive entry the day a species is authored that genuinely cannot relocate. If Nick prefers to add it anyway, the draft must at minimum stop asserting that Xylum never moves, because that assertion contradicts a ratified line.

## 5. Blocking items

1. **F1** — the `crystal` covering's `armored` and `shell` expectation must be stated to match what the script actually enforces, or the draft teaches an agent something false about the tooling.
2. **F2** — the bodyPlan selection rule's "a rooted body that never moves has no key" contradicts the ratified Xylum burrow band and must be rewritten before the open question is put to Nick.
3. **F8** — the stance-at-rest versus stance-in-the-pose rule. Two species split on its absence, and it is one sentence.
