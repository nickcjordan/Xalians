# Canonical v5 species definitions

The redesigned model and prototype generator are implemented and the complete roster has passed source, creative-coverage, calibration, compilation, and scale checks. Since 2026-10-06 (issue #796) this directory is the only creature roster: the public generator, the registry API, the encyclopedia and every game read it, and the v4 model is deleted.

Current staged species: 33 canonical species, including Fathomaw. Each has a same-key `*.ability-audit.md` recording sources, included/excluded mechanism families, essential guaranteed capabilities, deferred mechanics and verification. The original 32-species representation audit is [here](../../design/creature-roster-audit.md); the cross-roster rating pass is [here](../../design/creature-v5-calibration.md). The current prototype generator uses the ordinary `canonicalSpeciesCatalog.json` bundle, without a release ID or per-species revision. Every file in this directory ships; there is no separate manifest.

Current templates record mass as `massKg` and at least one applicable overall `heightCm`, `lengthCm` or `widthCm`. Additional overall dimensions are optional when they clarify the body. All declared measurements on an individual resolve from one size percentile. Frackworm's 900 to 1500 cm body extent is now length rather than height. The `schemaVersion` field in older v5 source files is optional compatibility metadata, not a field to add or bump in new prototype species. Existing frozen records keep their original fields and replay under their archived schemas.

The existing descriptions stay verbatim. The fluid-development v5 templates deliberately remove traits, archetypes, corporeality and complete-move pools. Since 2026-09-22 the ordinary act space is derived from the body rather than authored: registry tables in `packages/content/src/creature/acts.ts` turn a species' anatomy, its declared `channels` and its declared `conduits` into acts, `acts.exclude` removes only those contradicted by evidence, and `acts.output` re-bands one. An authored `mechanisms` entry is an extension for justified behavior those tables cannot express, such as Avilily's paralyzing saliva or Graviclaw's pull toward the performer. New and edited species require a logically exhaustive review of all derived acts, exclusions and possible extensions; compactness is not an exclusion reason. The contract is [docs/design/creature-derived-acts.md](../../design/creature-derived-acts.md). The generator compiles the full space once, then constructs four distinct actions per individual without per-creature review or retry. Four actions are not a species-level cap.

`fins` and the `lowlight` sense are ordinary `registries.json` rows since 2026-10-06; the v5 derived-act table supplies the fins strike and shove permissions. Frozen archives are unaffected because each carries its own copy of the vocabularies it used.

Check source files with `npm run check:creature-model -- docs/species-templates/v5/<key>.json`. After ratification run `node scripts/bundleLore.js`, then `node docs/species-templates/tools/validate-all.js`, `npm run check:species` and the generation tests. This updates current content only; it adds no archive or version marker. The package test `creatureCanonicalPilot.test.ts` exercises seeded generation and guaranteed identity across the roster. Each game's artwork and mechanics adoption remains separately scoped.
