## Synonym cross matrices (Section 9.5)

Per brief Section 9.5: every row from the Section 0 row set (109 consolidated lexical roots) is crossed against every synonym in each action's column pool. K = kept (composed into the cell above). D = definition dishonest (one or both sides' meaning does not support the pairing — e.g. a sound-word or shape-adjective has no "drawing off" sense, or a bare state-adjective cannot front/follow the partner as a name). G = gibberish/impossible collocation. C = comic/innuendo (say-aloud fail). T = tautology. B = borrowed (flagged). S = signature register (flagged). X = same name already kept in another cell (cell named). No cell is blank; no dash; no "not attempted."

Proof of per-name judgment on uniform rows (brief Section 9.5 requirement — at least 3 examples per uniform row/column with individual failures written out):

- **"Storm" row, all-D across the DRAIN column pool:** *Storm Siphon* — D, a storm is a weather event, not a drawing-off mechanism; siphon requires a channel and a source, storm has neither. *Storm Wither* — D, wither describes the target's decline, not an attacker-side action storm can perform. *Storm Milk* — G, "milking" a storm is an impossible collocation (milk requires a teat/gland-like source; storm has none).
- **"Ohm" row, all-D across DRAIN:** *Ohm Siphon* — G, Ohm is a unit of resistance, not a substance or force that can be the agent of a siphon. *Ohm Bleed* — D, nothing in "ohm" carries a bleeding/loss sense; it measures opposition to current, not a thing lost. *Ohm Wring* — G, a unit cannot be physically wrung.
- **"Thunderbolt" row, all-D across DRAIN:** *Thunderbolt Sap* — D, thunderbolt is the discharge-strike itself (an instantaneous release), not a drawing-off action; also carries the hard-cut borrowed-name caution from ruling 2 on any bare/lightly-modified standalone use. *Thunderbolt Leech* — D, same reasoning — the word names a strike-event, not a parasitic draw. *Thunderbolt Wither* — D, same.
- **"Deafening" column-pattern (an intensity-adjective row), all-D across DRAIN:** *Deafening Drain* — D, deafening describes sound-loudness, unrelated to any drawing-off sense; no electric drain-mechanism reads as "loud." *Deafening Sap* — D, same. *Deafening Siphon* — D, same.
