# PSYCHIC — Composed Names v5-c

Assignment: PSYCHIC element, actions SPRAY, BURST, CLOUD, SNARE only. Per COMPOSITION-BRIEF v5. Row set is the Section 0 productive-word list from `step0-psychic.md`, verbatim (reproduced below as Section 0). Inputs: `harvest-psychic.md`, `harvest-action-spray.md`, `harvest-action-burst.md`, `harvest-action-cloud.md`, `harvest-actions-snare-crush-mend.md` (SNARE section only).

Canon: PSYCHIC = Telypso — mind, empathy, dream-logic, telekinesis, hypnosis, precognition; physics behave like suggestions. Hard bans: puppeting (literal control of another's body), time reversal, true invisibility, teleportation, creating life, permanent transformation. The ⚑ CANON words from Step 0 (possess/commandeer/puppeteer/puppet/marionette/strings/thrall/servitude/compel/coerce/dominate/subjugate/override/manipulate/enthrall/obscure/veil/masked/warp/bend/rewrite) are judged per-name below: kept where the composed name reads as influence/suggestion/perception, rejected with code X-CANON ("canon: puppeting sense") where it unavoidably reads as literal body-control, or X-CANON-INVIS/X-CANON-TIME where it reads as true invisibility or time reversal.

Standing rulings respected: 1-2 words, no possessives, no hyphens, American English. Bare combining forms die; real-word compounds live. No bare action synonyms in element cells. One action cell per name. Grip/clutch/bind/coil/tether/lock restraint words go to SNARE (settled ruling — "grips always go to snare"), which is native territory here since this assignment covers SNARE directly. Haze/fog-class words live in CLOUD; bare Fog/Mist are water's words unless psychic composes a qualified "Mind Haze"-style name. Burst-words (detonation/eruption class) live in BURST. Material-defined words belong to their element (excluded here). Real-world weapons/military terms cut. Franchise move names cut or flagged. Anatomy-evoking names take instrument tags (channels for psychic: mind, gaze, voice, aura — no material body-part anatomy since psychic is not a physical-substance element in these four actions, but SNARE mind-grip names still take [mind] or [gaze] channel tags per rule 6.9). Dark owns Vortex/Stasis/Supernova/Tidal families — excluded here where relevant (Vortex, Undertow-as-water/dark, Maelstrom, Whirlpool).

## SPRAY

**Honest framing:** Psychic has no physical substance to expel — no fluid, gas, or particulate. Per harvest-psychic.md Section 4's own note, this action is "very thin" for psychic. The only legitimate compositions are (a) psychic nouns that denote something broadcast/scattered in a spreading pattern by definition — whispers, glimpses, flashes, sparks, impressions, notions, visions, thoughts — crossed with SPRAY's expulsion-pattern vocabulary (spray, spew, volley, torrent, wash, shower, cascade, barrage, fusillade, deluge, rain, broadcast, scatter), and (b) SPRAY verbs (broadcast, scatter, shower, fan out) that are already semantically about wide dispersal of many small units, which is exactly what "whispers"/"visions"/"impressions" are. Names that would require psychic to eject literal matter (mist, fog, haze, breath, foam, ooze, vapor) are excluded here as CLOUD- or other-element-owned, or rejected D. ## SNARE

**Honest framing:** Signature-strength cell per assignment. Psychic snare names are hypnotic/trance holds and mental binds — a legitimate, deep register (hold, grip, thrall, trance, hypnosis, mesmerism, suggestion, compulsion) distinct from SNARE's physical rope/net/trap vocabulary, which composes with psychic only in the figurative-restraint sense the SNARE harvest itself flags ("Web Trap [spinneret]," "Coil Bind [serpentine]" are anatomy-specific and NOT psychic's; psychic's version is "hold," "grip," "thrall," "trance" — the mental register of the same word family). Per standing ruling, grip/clutch/bind/coil/tether/lock words belong to SNARE — this cell is exactly where psychic's mind-grip vocabulary lands. Canon is the central constraint here: possess/commandeer/puppeteer/puppet/marionette/strings/thrall/servitude/compel/coerce/dominate/subjugate/override/manipulate/enthrall are ALL judged per-name below. The test applied: does the composed name describe *holding someone's will/attention/perception in place* (canon-fine — hypnotic trance, mental grip) or *making a body move like a puppet* (canon-banned)? Names built on Puppet/Marionette/Strings are rejected outright wherever the literal-puppeteering reading is unavoidable; Thrall/Servitude/Compulsion/Command survive because "held in thrall" and "under compulsion" are classic hypnosis/persuasion idiom, not literal body-animation, and the genre-standard reading (a target frozen/obedient in place, still their own body) matches SNARE's actual mechanic (restrain, immobilize) rather than BURST-style animation of another's limbs.
