# Xalian Catalog Harvest Brief (shared instructions for all Stage 1 harvest agents)

You are doing an exhaustive vocabulary harvest for a creature-collection game's ability-name catalog. Your launch prompt names your assigned SEMANTIC FIELD (one element medium or one action type) and the OUTPUT FILE you must write.

## Non-negotiable process rule
WRITE YOUR COMPLETE RESULTS to your assigned output file (Write tool, markdown) BEFORE finishing. Your final report should be only a 5-10 line summary (counts per section, which sub-fields were rich vs thin, anything you excluded at a boundary). The file is the deliverable; research not written to the file is lost.

## Mission
Harvest the ENTIRE English semantic field for your assignment. Exhaustive-first: do not stop at "enough" — the goal is every word that genuinely fits; curation happens later, not by you. Use scientific, poetic, archaic, nautical, technical, and folk registers. Real English words only.

## Hard constraints (violations get your work discarded)
- American English spelling. No em-dashes anywhere in your output.
- No modern idiom, internet slang, tech-product words (reboot, upgrade as slang), or jokey names.
- No Earth-fauna or real-species references (no Python Coil, Boa Crush, Cobra anything — this world has no Earth animals).
- No borrowed names from existing creature/monster games (no Hydro Pump, Shadow Ball, Earthquake-as-Pokemon-move etc. — if you recognize a candidate as an existing game's move name, exclude it and list it under "Excluded as borrowed").
- No combining forms as standalone words (chrono, hydro, pyro alone are not words; Hydro Beam style prefix-names are acceptable only if the compound reads as natural English).
- Candidate ability names: ONE or TWO words, natural English collocations only (would a native speaker put these words together?). Never a taxonomy recital.
- Definition honesty: if a word's literal definition ties it to a DIFFERENT domain than yours, exclude it no matter how good the metaphor feels, and list it under "Excluded as other-domain" with the domain named. Your launch prompt lists your specific adjacent-domain boundaries.
- Religious/spiritual register is permitted (Benediction, Grace). Keep it abstract.

## Deliverable format — TYPE A (element MEDIUM fields)
Sections: 1. Adjectives; 2. Nouns; 3. Verbs/gerunds (each one per line; add a 5-10 word definition for any non-everyday word); 4. Candidate ability names for EACH of the 16 action types below (as many good ones as the field honestly supports; report thin actions honestly rather than forcing bad names); 5. Excluded as other-domain / borrowed.
The 16 actions: strike (single direct blow), lash (sweeping arc), crush (grips and compresses), rake (rapid repeated cuts), shove (forces target out of position), drain (leeches vitality), ambush (closing burst ending in a hit), beam (focused line of energy), hurl (launched mass), spray (matter expelled in a spreading arc), burst (radial release from self), cloud (lingering emitted area), snare (holds, drags, or slows), ward (protects), mend (restores), terrorize (erodes courage nearby).

## Deliverable format — TYPE B (ACTION fields)
Sections: 1. Nouns; 2. Verbs/gerunds (definition rule as above); 3. ELEMENT-NEUTRAL candidate names (must read fine for a fire, water, ghost, or psychic creature EQUALLY — if a name leans any element, it is NOT neutral: move it to section 5); 4. Anatomy/mechanism-implying words (table: word → implied anatomy; e.g. vise → pincers/jaws, coil → serpentine body, web → spinneret) — these get instrument tags downstream; 5. Element-leaning candidates (good names that belong to a specific element's column — name the element); 6. Honest richness assessment of your field's sub-concepts.
