# Composed Catalog — ROCK, actions DRAIN / AMBUSH / BEAM / HURL (v5-b, Composition Brief v5 compliance run, 2026-09-01)

Element: ROCK — stone, earth-mass, seismic force, asteroids (homeworld Stonera). This run composes only the four assigned actions: DRAIN, AMBUSH, BEAM, HURL. Canon per assignment: HURL is rock's deepest signature (thrown stone is the primal projectile); per the 2026-09-01 material-word ruling the names Boulder Toss, Rubble Hail, Rock Volley, and Stone Salvo are reserved OUT of the neutral pools FOR rock — all four are placed here, and the rest of the HURL register is composed around them. DRAIN is honestly thin (petrifying-leach register only; nothing implying permanent transformation — canon ban on that reading is enforced per-name below). AMBUSH is rockfalls and rockslides from above. BEAM is honestly near-empty (stone does not emit); thin is accepted as honest rather than padded.

Standing rulings applied as law (this run's assignment):
1. Avalanche is ICE-owned; ROCK cross-references it only, never claims ownership — no "Avalanche"-headed name is composed into any ROCK cell in this run.
2. No borrowed names: Rock Slide, Rock Throw, Stone Edge, Ancient Power are exact borrows and are cut wherever they would otherwise surface, flagged B. Rockslide and Rockfall as single fresh words are honest and productive; the two-word "Rock Slide" specifically is the borrow, not the concept.
3. No real weapons/modern-tech: Catapult/Trebuchet/Ballista/Mangonel/Onager-class siege engines are ratified cuts (W) wherever they would surface from the HURL harvest's mechanism/anatomy vocabulary; Sling is fine (kept, not a weapon-class cut).
4. No bare litho-/geo- combining forms (already excluded at Step 0; none reappear here).
5. Anatomy-evoking names are KEPT with instrument/channel tags from the brief's registry.
6. One name, one cell; a name already kept in a different action's cell within this run is coded X and the correct cell is named.
7. "Redundant" is NOT a rejection code. Near-duplicates within the SAME cell are both kept (Vitality Drain and Vital Drain, Boulder Barrage and Boulder Volley, etc. all stay).
8. Canon ban enforced per-name: no name may imply permanent transformation (petrify-family words are scoped to a combat-damage/weakening reading — "turns the target briefly brittle/leaden," not "turns the target to stone forever" — any name that reads unavoidably as permanent transformation is cut, coded D, canon).
