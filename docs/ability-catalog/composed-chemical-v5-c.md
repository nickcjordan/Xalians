# Composed — CHEMICAL — spray / burst / cloud / snare (v5-c)

Composer scope: CHEMICAL element, actions SPRAY, BURST, CLOUD, SNARE only. Follows COMPOSITION-BRIEF.md v5 in full. Row set is the verbatim Step-0 productive-word list from `step0-chemical.md` (reproduced in Section 0 below with the same classifications — this composer did not re-derive or alter it). Inputs: `harvest-chemical.md`, `harvest-action-spray.md`, `harvest-action-burst.md`, `harvest-action-cloud.md`, and the SNARE section of `harvest-actions-snare-crush-mend.md`.

Element canon (binding): CHEMICAL = Drainov — toxins, acids, corrosion, volatile reactions, industrial meltdown residue, living chemical weapons. Boundary rulings applied throughout: miasma-class disease-vapor words are chemical-primary with GHOST dual-candidate flags; liquid-medium phase words flag to WATER (phase is water's, chemistry is chemical's — kept chemical-primary); venom/toxin are chemical-primary at the PLANT border; sap is plant-primary (avoided here except where explicitly noted); real chemical-weapon proper names are HARD CUTS at composition (code W, reason "real weapon") even though Step 0 keeps them grammatically productive.

Standing rulings honored: 1-2 words, no possessives, no hyphens, American English. Bare combining forms die; real-word compounds live. No bare action synonyms alone in element cells. One action cell per name (a name appearing legitimately in two cells is cross-referenced with code X, not duplicated). Scatter verbs (Shower/Spray/Scatter/Plume) home in SPRAY; haze-words home in CLOUD; burst-words (detonation/eruption) home in BURST; all grip/clutch/bind/coil/tether/lock/adhesive-hold words live in SNARE (sticky/adhesive/congealing holds are chemical's snare register). Material-defined words belong to their element. Bare fog/mist compounds are water's; chemical fume/vapor/gas compounds are chemical's. Real-world weapons/military terms cut. Franchise move names cut or flagged. Anatomy-evoking names carry instrument tags (secretion, breath, fangs, stinger, etc.) — never register cuts. Dark owns Vortex/Stasis/Supernova/Tidal.
