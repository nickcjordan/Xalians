# Composed — ELECTRIC — Actions: SPRAY, BURST, CLOUD, SNARE (v5-c)

Composition Brief v5 followed in full. Row set is the verbatim productive-word list from `step0-electric.md` (171 productive words: 63 adjectives, 62 nouns, 46 verbs/gerunds). Inputs: `harvest-electric.md`, `harvest-action-spray.md`, `harvest-action-burst.md`, `harvest-action-cloud.md`, and the SNARE section of `harvest-actions-snare-crush-mend.md`.

Element canon for this run: ELECTRIC = lightning, voltage, electrical current, plasma, storm-as-lightning (homeworld Zolton; bloodstorms — crimson lightning sprites — are lore-native). Burst is electric's signature register (discharge, thunderclap-as-shock). Cloud = charged air, ionized field, static haze. Snare = paralysis-by-shock (locked muscles, honest register) plus magnetic pinning. Spray = scattered sparks, arc showers. Water-flow words belong to WATER (current-as-flow, cascade-as-waterfall, torrent, deluge, gush, geyser, fountain); wind words belong to AIR (gale, squall, gust) — flagged, never claimed as electric's own.

Standing rulings treated as law (never reversed in this run):
1. No prior consolidated electric file exists; harvest candidates are a starting point only, not a ceiling.
2. Hard cut classes: borrowed creature-game names (Discharge, Thunder Wave, Static, Spark as BARE standalone names are the highest-risk borrows — flagged B; fresh compounds using these words are fine); real weapons/modern-tech idiom (EMP, Taser, Firehose, Power Wash); Earth fauna/flora; bare electro- combining forms (no bare "Electro" anything); no reality-breaking implications (no time reversal, teleport, true invisibility, life creation).
3. Target-state paralysis names (naming the target's condition: "Paralyze," "Stun") fail rule 6.2/definition-honesty as a D — the actor's act is named instead (a Numbing Arc, not a Paralyze Arc). This run avoids that construction throughout SNARE.
4. Anatomy-evoking names are KEPT with instrument tags; "doesn't fit electric's register" is never a valid cut reason.
5. One name, one cell; out-of-scope pairings get X naming the correct cell, never a silent drop.
6. "Redundant" is not a rejection code; near-duplicates are welcome throughout.
