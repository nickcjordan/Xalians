# Ghost Element — Section 0: Productive-Word List

Element: GHOST — the spectral, incorporeal, haunting register (homeworld Phantiri, a tombworld whose abandoned Generator produces non-corporeal Xalians inhabiting the Dreadscape). Ghost owns the spooky-shadow/haunting register that DARK explicitly does not (dark = gravity/void physics). This is Step 0 only (Composition Brief v5 Section 4): every noun/adjective/verb concept from `harvest-ghost.md` sections 1-3, classified PRODUCTIVE or NON-PRODUCTIVE. Only grammatical/formal reasons justify non-productive status (multi-word phrase that cannot compose to 2 words, a bare combining form/prefix, or a word that cannot grammatically front/follow a partner). Register, tone, theme, and abstractness are never valid exclusion reasons. Boundary and canon-sensitive words are flagged inline per the assignment (not excluded here) and collected in the Flags note at the end. This file feeds four downstream composers as a shared verbatim row set — no cells or matrices are produced here.
