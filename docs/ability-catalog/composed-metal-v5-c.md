# Composed — METAL — SPRAY / BURST / CLOUD / SNARE (v5-c)

Assignment: METAL element, actions SPRAY, BURST, CLOUD, SNARE only. Follows COMPOSITION-BRIEF.md v5. Row set is step0-metal.md verbatim (137 productive concepts — 55 adjectives, 61 nouns, 21 verbs/gerunds, post-collapse). Element canon: METAL = alloys, bladed material, machined mass, magnetism-as-metal (homeworld Veridium, an all-metal factory world/possible worldship).

Standing rulings applied as law:
1. No borrowed names (Metal Sound, Mirror Shot class flagged B on sight; harvest-metal.md's own excluded-as-borrowed list — Steel Wing, Iron Head, Gear Grind, Metal Claw, Metal Sound, Metal Burst, Flash Cannon, Shift Gear, Iron Defense, Iron Tail — never re-composed here).
2. No real-weapon proper names (no Torpedo/Depth Charge class).
3. Bare ferro- forms and other combining forms never front or stand alone (rule 6.7); step0-metal.md's own non-productive rows (Case-hardened, Cold-forged, Ferrous, Tungsten-tipped, Armor plate, Pig iron) are never re-litigated as names.
4. Anatomy-evoking names are KEPT with instrument tags from the registry, never cut for being anatomical.
5. One name, one cell.
6. "Redundant"/"near-duplicate" is NEVER a rejection code; near-duplicates are welcome per brief Section 1.
7. Material-word ruling: Steel Trap and Iron Grip are reserved FOR metal (out of the neutral snare pool) — both placed in SNARE below, tagged where anatomical, with the full chains/shackles/manacles/cage register composed on METAL roots (Iron Chain, Steel Shackle, etc.) — these are metal's own distinct compounds, separate from dark's Void/Gravity/Mass Chain-Shackle-Manacle-Cage family, which stays dark-owned and is never re-keyed here.
8. Forge/kiln-register compounds (Forge, Brazier, Crucible, Foundry, Smelting) are flagged per step0-metal.md as bordering FIRE (which owns Forge/Furnace compounds); metal retains the roots for machining-adjacent, non-forge-headed compounds and flags any Forge-headed name for the auditor.
9. Magnetism (Magnetized) and Coil (metal-spring sense) border ELECTRIC; both elements may own their own compounds — flagged, not excluded.
10. Modern-machine idiom cluster (Piston, Servo, Bearing, Chassis, Cog, Cylinder, Gear, Grille, Hinge, Linkage, Machined, Ratchet, Retractable, Rotor, Sprocket, Strut) carries Veridium factory-world latitude per step0-metal.md but is flagged prominently per the modern-tech rule at every use.

Chain Coil / Wire Coil (snare) use "coil" in the metal-spring/wound-metal sense per step0-metal.md's own disambiguation note, not the electrical-coil sense; flagged for the auditor's awareness of the shared surface form.
- **Modern-machine idiom instances used:** Piston Spasm (burst), Ratchet Lock (snare) — both flagged per the modern-tech rule; Veridium's factory-world/possible-worldship lore gives metal wider latitude than other elements per step0-metal.md, but the flag is raised at point of use as instructed.

- **Cross-cell definition tension:** Slag Vapor (spray) sits near the spray/cloud boundary — molten slag genuinely off-gasses at temperature, so the *expulsion* of that gaseous-adjacent matter is spray-honest, while the *lingering* haze it leaves behind would be cloud's Slag Pall/Slag Murk (both kept separately in cloud). Wire Mist (spray) has the same boundary tension, resolved the same way — the expulsion is spray, the lingering result is cloud's Filings Haze/Filings Mist family.
- **Anatomy tags applied per registry:** Steel Trap [jaws], Iron Grip [fists], Vise Snare/Vise Lock/Vise Clutch [pincers], Gauntlet Grip/Gauntlet Clutch/Studded Grip [fists], Chain Coil/Wire Coil [coils], Chain Grasp [tendrils, coils], Filings Spray/Filings Gout/Slag Gout/Filings Plume/Molten Fountain/Slag Geyser [vent] per the spray harvest's own anatomy table (a dedicated bodily port/gland outlet for particulate/molten expulsion).
- **Borrowed-name suspicion:** none newly identified; every kept name checked against harvest-metal.md's own excluded-as-borrowed list (Steel Wing, Iron Head, Gear Grind, Metal Claw, Metal Sound, Metal Burst, Flash Cannon, Shift Gear, Iron Defense, Iron Tail) and the general franchise-move-name risk class named in the brief — no exact or near-exact matches found among the kept names above.
