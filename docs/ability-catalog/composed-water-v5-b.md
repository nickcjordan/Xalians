# Composed Catalog — WATER, actions DRAIN / AMBUSH / BEAM / HURL (v5-b, Composition Brief v5 compliance run, 2026-09-01)

Element: WATER — the liquid medium itself in all its forms and behaviors (tides, currents, waves, pressure, depths, mist, springs). Never spooky, never wind-defined, never ice-defined. Fog/mist are water-owned (condensed water vapor).

Scope: this run composes only the four assigned actions — DRAIN, AMBUSH, BEAM, HURL — completing the cross around the ratified keeps already present in `composed-water-v4.md`. It does not re-open strike/lash/crush/rake/shove/spray/burst/cloud/snare/ward/mend/terrorize, which remain as ratified in v4.

Row set: Section 0's productive-word list is used VERBATIM from `composed-water-v4.md` (reproduced below unabridged, including non-productive/held/dual entries for full accounting) — not re-derived.

Standing rulings applied as law, never reversed:
1. Names already kept in v4's DRAIN/AMBUSH/BEAM/HURL cells are ratified keeps.
2. Ratified cuts, never re-keep: Aqua/Hydro combining-form compounds; Depth Charge; Torpedo; Geyser Toss; Spring Cast; Water Globe Hurl.
3. The drag rule: riptide/undertow/drag words serve only snare/ambush/shove — they MAY serve ambush, never drain. Containers (reservoir, aquifer, jar) CAN be drained but cannot crush or ward. Vital Tide is a ratified cut.
4. Held for the designer, in no cell: Squall, Monsoon, Waterspout.
5. One name lives in exactly ONE action cell; a sound-but-misplaced pairing is coded X to the correct cell.
6. Anatomy-evoking names are KEPT with instrument tags per rule 6.9.
