- **UPHOLD** — the rejection also cited a genuine ground (definitional mismatch, etc.) or the name is already owned elsewhere under rule 5 (one name, one cell).
- **ARTIFACT** — the line is a block-row parse pattern describing a uniform-verdict pattern across a whole column set, not a specific name rejection.
