### A.2 Disposition notes for non-kept psychic words in this cell

The overwhelming majority of the 389-word row set does not compose honestly against DRAIN's synonym pool — DRAIN's pool is about a taking/siphoning mechanism, and only psychic nouns naming a mental resource, or verbs/adjectives describing a state that can be "drained," compose. Concrete illustrative examples of D-coded (definition-dishonest) rejections, written per-name as required:

- "Lucid Drain" — D. Lucid is a quality-adjective describing clarity of a mental state, not a resource or a draining mechanism; "Lucid Drain" reads as nonsense (draining lucid-ness is not what "lucid" modifies).
- "Telepathic Siphon" — D. Telepathic is a channel/method adjective (how communication happens), not a substance that can be siphoned; the pairing does not parse as "siphoning telepathically" nor as a coherent noun phrase.
- "Prophecy Tap" — D. A prophecy is a discrete statement/event, not a continuous resource that can be "tapped" the way a vein or reserve is; the collocation is dishonest to both words' definitions.

## Section B — AMBUSH cell

## Section D — HURL cell

Telekinetic hurl is a signature-strength cell per assignment: telekinesis is canonically sanctioned (not banned), and "hurling mass with the mind" is one of the most iconic psychic-genre actions. HURL's pool (throw, toss, fling, hurl, launch, volley, cast, heave, catapult, sling, propel, project, eject) pairs with psychic's telekinesis/force/mind vocabulary. Note per hard rule: HURL implies a *physical mass* being thrown — psychic supplies this via telekinetic *instrument* words (Mind, Will, Telekinetic, Psychic) fronting a hurl-verb, describing the mechanism (mind-power throwing something) rather than the element supplying the thrown substance itself (there is no "psychic matter" — the harvest is explicit about this gap). This keeps the cell definition-honest: these names describe the *method* of hurling, not a hurled psychic substance.

## Section 9.5 — Synonym cross matrices
