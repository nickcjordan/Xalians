# SAND — Section 0: Productive-Word List

Source: harvest-sand.md sections 1-3. Every noun/adjective/verb concept classified PRODUCTIVE or NON-PRODUCTIVE per Composition Brief v5 Step 0. Only grammatical/formal reasons justify non-productive status. Register/tone/theme are never valid exclusion reasons. Boundary notes (rock, air, water/mire, glass) are flagged inline per assignment but do NOT exclude — flags carry into the disposition table for the composers.
