# Composed Catalog — FIRE — Actions: STRIKE, LASH, RAKE, SHOVE (Composition Brief v5, RE-RUN)

Assignment: FIRE element, actions STRIKE, LASH, RAKE, SHOVE only. This is a re-run. The prior attempt (composed-fire-v5-a, superseded by this file) failed by keeping roughly 40 of 50 synonyms for nearly every hot adjective, producing an 819-name STRIKE cell from 59 words, including "Blazing Sock," "Molten Belt," "Roasting Headbutt," and "Scalding Swat." That output is discarded; this file re-composes all four cells under corrected calibration.

**Calibration for this run (law for this file):** K is an AFFIRMATIVE judgment, not a default. A name is kept only if it is logically sound by BOTH words' definitions AND passes the say-it-out-loud test as a creature-battle move name — spoken aloud in a duel announcer's voice, does it land as a real move name or as something else (laundry, a dismissive gesture, a sound effect, a non sequitur)? Specific rulings carried through every cell below:
- **Sock, Belt, Cuff are comic homonyms** (laundry/clothing register) and fail say-aloud in combination with essentially every fire word tested — cut C throughout, named per-name below, not cut as a class without examples.
- **Swat** is a dismissive flick ("swat a fly") that undersells any fire word's intensity — fails say-aloud (tonal mismatch, not gibberish) for nearly every fire word; judged per-name.
- **Headbutt/Kick/Stamp/Trample/Punch/Jab-class anatomy verbs require the [instrument] tag** and only make honest sense where a body part is plausibly delivering the blow. This is a real per-name judgment, not automatic: "Roasting Headbutt" (a creature's skull, superheated, delivered as a ram) is a defensible keep; many others in this class fail because the fire word doesn't honestly modify a body-part delivery (e.g., a state-adjective like "Consuming" cannot modify "Kick" — consuming describes an ongoing process, not a foot).
- **Obscure verbs (Fell, Deck, Stave, Jar)** mostly fail say-aloud as archaic/awkward for a modern move-name catalog; judged per-name, most cut.
- Target density: roughly 30-150 kept names per cell. Wide is still correct — near-duplicates on different fire roots (Flame Slam, Ember Slam, Magma Slam) all coexist — but each is individually earned, not defaulted.

Element canon: FIRE = combustion, heat, flame, ash, magma/volcanic register (homeworld Magmuth; magma/lava words fire-owned, flag rock duals per standing dual-material convention). Never electric (spark boundary flagged, not used). Never light-as-illumination (glow boundary flagged — Glowing/Incandescent kept only in ember-glow/heat-of-metal sense per step0-fire.md, flagged wherever a name could misread as pure illumination).

Standing rulings applied silently throughout (law, never reversed):
1. No prior fire consolidation exists other than the discarded first attempt; step0-fire.md and harvest-fire.md candidate names are starting points only.
2. No borrowed creature-game names (Fire Punch, Blaze Kick are famous borrows in existing creature-battler franchises — both are exact-match hard cuts, not merely flagged, since they are literal existing move names, not generic English); other near-misses are flagged B and kept per "unsure = flag, keep."
3. No real weapons/modern-tech; "Incendiary X" compounds are judged per-name against the ordnance-idiom risk (an incendiary device is real-world ordnance) — kept where the second word is a body/action word rather than a delivery-mechanism word, cut W where it reads as a munitions compound.
4. No Earth fauna/flora.
5. No bare pyro- combining forms (Pyroclast is non-productive per step0, excluded from the row set entirely).
6. Steam is a fire/water boundary word — flagged, not owned outright by fire; not present in this harvest's productive list (harvest-fire.md's lexicon sections do not include "Steam" as a fire noun), so it does not arise as a row here.
7. Anatomy-evoking names are KEPT with mandatory instrument tags from the registry (jaws, fangs, beak, tusks, horns, antlers, trunk, tongue, crest, lure, claws, talons, fists, hooves, pincers, blades, spurs, wings, tail, stinger, rattle, coils, hide, shell, spines, tendrils, roots, pseudopods, spinnerets, light-organs, vents, core, antennae, body, or channels mind/gaze/voice/breath/secretion/swarm/aura) — never cut for being anatomical, but the tag is mandatory and its absence is itself a defect worth flagging.
8. One name, one cell; "redundant" is never a rejection code.

## Section A — Standalone words per action

A productive word is a standalone name only if, alone, it evokes the specific action without a partner word.

**Strike:** none of the 59 rows read as a complete strike-name alone — fire's lexicon is entirely modifier/state/process vocabulary (adjectives describing heat-state, nouns naming fire-things, verbs naming combustion processes), with no bare noun that itself denotes a single blow the way "Icicle" or "Berg" does for ice. Every strike name below is a compound.
**Lash:** none stand alone; fire supplies no word meaning "a whip-like sweeping arc" by itself.
**Rake:** none stand alone; fire supplies edges and burns, not a bare word meaning "repeated cutting motion."
**Shove:** none stand alone; fire supplies heat and mass-in-eruption nouns (Firestorm, Wildfire, Conflagration) but none of them alone denotes displacement of a target the way "Avalanche" does for ice — they name spreading/burning events, not directed force against one thing. Judged and rejected individually in Section C below rather than assumed.
