# Composed — ELECTRIC — STRIKE / LASH / RAKE / SHOVE — v5-a (RE-RUN)

Per COMPOSITION-BRIEF v5. Actions assigned: STRIKE, LASH, RAKE, SHOVE only.

**Re-run notice:** a prior attempt at this exact assignment flooded — 1,413 kept names in Strike alone, produced by crossing every element word against every synonym with no per-name judgment (roughly ten synonyms auto-kept per word). This run applies genuine per-name affirmative judgment: a name is kept only if it is logically sound by BOTH words' definitions AND passes the say-it-out-loud test as a creature-battle move name. Expected cell width per the brief's own calibration is roughly 30-150 kept names per cell; hundreds-to-thousands means the judgment step was skipped. This run holds that line deliberately, including rejecting entire columns of weak synonyms (e.g., dismissive/comic strike-words: Sock, Belt, Cuff, Swat; obscure archaic verbs: Fell, Deck, Stave, Jar) rather than composing every element word against them by rote.

Element canon (assignment): ELECTRIC = lightning, voltage, electrical current, plasma, storm-as-lightning (homeworld Zolton). Water owns current-as-flow (electric owns current-as-electricity; both keep their own "current" compounds — settled practice, flagged, never reversed). Air owns wind/storm-as-wind — Squall, Gale excluded from electric's cells on that ground. Fire owns spark-as-ember — electric owns spark-as-electrical-discharge; both keep "spark." Light-domain dual candidates (Radiant, Incandescent, Blinding) are judged honestly per-cell, not auto-included or auto-excluded.

Standing rulings (law, never reversed):
1. No borrowed creature-game names (Thunderbolt, Thunder Punch, Volt Tackle, Spark, Wild Charge are famous borrows — flag exact/near matches B; fresh compounds are fine).
2. No real-world weapons or modern-tech (Taser, Railgun, EMP).
3. No Earth fauna/flora.
4. No bare electro- combining forms; no bare Hydro/Aqua-class fronting either (n/a here, electric-specific: no bare "Volt-" or "Amp-" combining-form fronting).
5. Anatomy-evoking names are KEPT with instrument tags from the registry, never cut for being anatomical.
6. One name, one cell; "redundant" is NOT a rejection code — near-duplicates on different roots are welcome (Volt Slam, Storm Slam, Plasma Slam coexist).
