# Composed Catalog — METAL, actions DRAIN / AMBUSH / BEAM / HURL (v5-b, Composition Brief v5 compliance run, 2026-09-01)

Element: METAL — alloys, bladed material, machined mass, magnetism-as-metal (homeworld Veridium, an all-metal factory world, possibly an ancient worldship). Standing rulings applied as law for this run:

1. No borrowed names (Flash Cannon, Magnet Bomb, Gyro Ball are famous borrows in other creature-collection franchises — any exact-string match is flagged B and kept per "when in doubt, keep and flag," never silently cut). Bomb/Cannon-headed compounds also independently fail the no-real-weapons rule (W) where they surface.
2. No real-weapon proper names (a named historical weapon, e.g. Excalibur, Katana); generic blade/lance/edge vocabulary is metal's own and is not itself a weapon-proper-name violation.
3. No bare ferro- forms (Ferrous already excluded at Step 0 as a bare combining-form register root).
4. Anatomy-evoking names are KEPT with instrument/channel tags from the brief's registry (rule 6.9); a metal creature's claws, jaws, fists, tail etc. are exactly as legitimate as any other element's.
5. One name, one cell; out-of-scope pairings that fit a different action are coded X, naming the correct cell even when that cell is outside this run's scope.
6. "Redundant" is NOT a rejection code. Near-duplicates within the SAME cell are both kept (Osmosis/Osmotic Drain-style). X is reserved for true cross-action duplication only (an identical name string already kept in a DIFFERENT action's cell within this run).
7. DRAIN register for metal is scoped to the magnetic leach and the rust-that-eats register per assignment; rust/corrosion-family words are not present as standalone rows in the Step 0 productive list (no bare "Rust" row exists in the metal harvest lexicon), so rust-flavored drain names are not composed here — this is an honest gap, not a silent skip, and is recorded in the disposition table.
8. AMBUSH register: per the material-word ruling, "Steel Trap" belongs to metal materially but its honest action-home is SNARE (a trap restrains, it does not close on the target with a burst of speed). Any Steel Trap/trap-family candidate that surfaces in this run's Step C sweep is coded X to snare, not composed into ambush.
9. BEAM register is deliberately lean per assignment — metal's harvest itself found beam "thin to nonexistent" (metal has no natural coherent-light-beam connotation); this run leans on reflected-gleam and magnetic-line imagery rather than forcing a heat/light register that belongs to Fire/Light/Electric.
10. HURL register judges machine idiom (ball bearing, etc.) per-name against the modern-tech rule, with Veridium's factory-world lore giving metal wider latitude than other elements per Step 0's own note — flagged inline, not blanket-excluded.
