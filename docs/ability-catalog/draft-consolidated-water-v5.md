# Draft Consolidated Catalog — WATER, all 16 actions (v5, pending Fable audit)

## Pipeline

This file is the mechanical merge of a four-way composition fan-out plus a restoration sweep, in three stages:

1. **Composition fan-out.** Four composer agents each handled 4 of the 16 action cells for the water element: `composed-water-v5-a.md` (STRIKE, LASH, RAKE, SHOVE), `composed-water-v5-b.md` (DRAIN, AMBUSH, BEAM, HURL), `composed-water-v5-c.md` (SPRAY, BURST, CLOUD, SNARE), `composed-water-v5-d.md` (CRUSH, WARD, MEND, TERRORIZE). Each ran the full Composition Brief v5 Section 9.5 synonym cross for its four actions and produced a final "kept (N)" flat list per cell.
2. **Mechanical merge.** This document assembles those 16 flat kept-lists into one catalog, resolves the handful of dual-element names (Tidal Lash, Vortex) to cross-reference-only status, and flags every name that turned up kept in more than one cell (a violation of the "one name lives in one cell" rule that the four independent composer runs did not catch against each other).
3. **Restoration sweep.** A separate extraction pass pulled every name any of the four files rejected specifically for a stated reason that mentions "redundant," `X`, or "weak" — 714 lines total, in `redundancy-rejections-water.txt` — because the ratified project philosophy explicitly treats REDUNDANCY ALONE as an invalid cut reason (near-duplicate names across different root words are welcome, e.g. Wave Slam / Surge Slam / Deluge Slam already coexist). Each of the 714 lines was individually judged against a six-clause restoration policy (same-root duplication, light-tap/mass-word mismatch, an independent definitional reason riding along with the redundancy claim, identical-name-already-kept-elsewhere, neutral-pool collision, and named standing rulings) and resolved to either RESTORED (added back into its cell, marked with a trailing `°`) or UPHELD (left cut, with the controlling clause cited).

**This file is pending a Fable (human-facing agent) audit pass before being finalized.** Nothing here should be treated as final canon until that review lands — in particular the several genuine cross-cell name collisions the four independent composer files produced against each other (see "Input inconsistencies" below) were resolved by this merge pass using judgment calls that the auditor should specifically re-check.
