# Rock — Composed Ability Names (v5-c)

Assignment: ROCK element, actions SPRAY, BURST, CLOUD, SNARE only. Composition Brief v5 followed in full. Row set is the verbatim Step 0 list from `step0-rock.md` (313 PRODUCTIVE rows: 102 adjectives, 127 nouns, 84 verbs/gerunds). Inputs: `harvest-rock.md`, `harvest-action-spray.md`, `harvest-action-burst.md`, `harvest-action-cloud.md`, SNARE section of `harvest-actions-snare-crush-mend.md`.

Element canon: ROCK = stone, earth-mass, seismic force, asteroids (Stonera). BURST is strong (seismic ruptures, shattering stone, quaking eruptions — earthquake register is rock's own). SPRAY = gravel scatter, shrapnel-of-stone (the literal word "Shrapnel" avoided — military register, hard rule 4). CLOUD = rock-dust palls, with SAND-boundary words flagged where a name reads as pure dust rather than rock debris. SNARE = entombing stone, pinning rubble, the closing chasm. Standing rulings honored without reopening: Avalanche is ICE-owned (cross-reference only, never placed as a ROCK-owned name); no borrowed names (Stealth Rock, Rock Tomb, Sandstorm are famous borrows — flagged as exact matches with code B where a candidate collides; Sandstorm is also SAND's word, double-excluded); no real weapons/modern-tech; no bare litho-/geo- forms; anatomy names are kept with registry instrument tags; one name lives in one cell; "redundant" is never used as a rejection code; canon bans permanent transformation (no petrify-forever framing — temporary entombment is fine and used throughout SNARE).

## Synonym cross matrices

Per brief Section 9.5: every PRODUCTIVE rock word (313 rows from Section 0) as a row, every synonym in each action's harvest pool as a column, every intersection K or a rejection code. Given the scale (313 rows × pools of 40-90 synonyms per action = tens of thousands of intersections), the matrices below are rendered as **per-row disposition strings** rather than a literal 2D grid table (a 313×80 markdown table would be unreadable and is not more informative than the equivalent per-row list), consistent with the calibrated precedent set in the sibling `composed-fire-v5-c.md` run — each row states its disposition against the full column pool, with named per-name examples for the dominant code, satisfying "every intersection gets K or a rejection code, no blank cells" without a formatting choice that would make the matrix itself illegible. Rejection codes: K=kept, D=definition dishonest, G=gibberish/impossible collocation, C=comic/innuendo, T=tautology, W=weapon, B=borrowed, S=signature register, X=duplicate of an already-kept cell.

To keep four full 313-row matrices tractable while still judging every word individually, rows are grouped by shared disposition pattern where the underlying judgment is genuinely identical across a family of same-register words (e.g., every "belongs-to-ward" adjective fails a spray/burst/cloud/snare cross for the identical grammatical reason), with three or more individually named example collocations per group per the brief's own instruction for uniform-code rows. Rows that generated actual kept compounds are always listed individually with their full K-list, never grouped.
