# Composed Catalog — WATER, actions CRUSH / WARD / MEND / TERRORIZE (v5-d, Composition Brief v5 compliance run, 2026-09-01)

Element: WATER — the liquid medium itself in all its forms and behaviors (tides, currents, waves, pressure, depths, mist, springs). Never spooky (terrorize works through drowning/depths/pressure dread, not ghosts), never wind-defined, never ice-defined. The neutral-territory healing register (Algael lore) makes water the richest MEND element; religious/ritual register is allowed (Baptism, Ablution are ratified keeps).

Scope of this file: CRUSH, WARD, MEND, TERRORIZE only. Row set is the Section 0 productive-word list from `composed-water-v4.md`, used verbatim — every word marked PRODUCTIVE there is a matrix row here; no re-derivation, no subsetting. This file inherits v4's Section 0 in full (not reproduced here in full — see v4 lines 9-172 for the complete productive/non-productive table) and preserves all ratified keeps and ratified cuts for these four cells without reversal in either direction.

Standing rulings applied (law, not reversed):
1. Names already kept in v4's CRUSH/WARD/MEND/TERRORIZE cells are ratified keeps — included below; this run completes the cross around them.
2. Ratified cuts, never re-keep: Aqua Ward and all Aqua/Hydro combining-form compounds; Spring Rekindle; Tide Flare; Current Restorative; Tide Jar; Tide Sneak.
3. Containers (reservoir, aquifer, lagoon-as-vessel, jar) cannot crush or ward. Sources (wellspring, font, spring) mend, they do not strike. Pressure/depth words are water's core crush register.
4. Signature-register names grander than two plain catalog words are flagged S, never placed in cells.
5. Squall, Monsoon, Waterspout held for the designer — placed in NO cell.
6. One name lives in exactly one action cell chosen by definition; cross-cell tensions noted in flags.
7. Anatomy-evoking names kept with instrument tags: Tide Vise [pincers, jaws, tendrils], Abyssal Glare [gaze], Abyssal Roar [voice], coils/tendrils reserved for constriction names.
