## 5. Excluded as other-domain / borrowed

**Excluded as other-domain (ghost/dread/specter)**
Phantom, Specter, Spectral, Wraith, Ghostly, Haunt (as a noun meaning ghost-place), Haunting (adjective), Dread, Dreadful, Terror (as a proper standalone dread-register noun — kept only the verb "terrorize" per action-type list, treated cautiously), Eerie, Spooky, Macabre, Grim, Sinister (leans ghost/dark), Possession (kept the verb "possess" for mind-control sense but the noun "Possession" alone reads too strongly toward demonic/ghost horror — flagged, use qualified as "Mental Possession" if needed), Apparition, Specimen of the undead vocabulary generally.

**Excluded as other-domain (gravity/time)**
Foreknowledge kept (foresight-adjacent, fine), but excluded: Rewind, Time Loop, Temporal, Chronal, Chrono-, Gravity, Gravitational, Weighty, Orbit, Pull (gravitational sense — kept "Grip"/"Hold" for psychic-control sense instead), Time Warp (excluded — "Warp" alone kept for perception-warp sense, but "Time Warp" specifically excluded as time-rewind), Déjà Vu (borderline; excluded as it implies actual time-loop mechanics rather than foresight), Retrocognition (excluded — implies literal past-viewing/time mechanic bordering on the time-rewind boundary; kept precognition/foresight side only).

**Excluded as borrowed (recognized as existing game move names)**
Confusion (as standalone move name — a very well-known existing game ability; used only within compound original phrases like "Confusion Cloud" per brief's guidance on natural compounds, flagged for downstream review), Psychic (as a standalone move name, itself a known existing move title — retained only as the adjective in original compounds, e.g. "Psychic Beam", never bare), Hypnosis (as a standalone move name, existing game title — retained the broader family "Hypnotic," "Mesmerize," "Mesmeric Hold" etc. as originals, flagged "Hypnosis" itself for exclusion as a bare name), Dream Eater — excluded (recognizable borrowed name), Future Sight — excluded (recognizable borrowed name), Calm Mind — excluded (recognizable borrowed name, though "calm"/"mind" vocabulary retained individually for other compounds), Light Screen / Reflect — not applicable to this field, noted only to confirm no overlap.

**Sub-field richness note:** foresight/clairvoyance, hypnosis/trance, and empathy/calm registers are very rich. Illusion/perception-warping is rich for cloud/ward/mend actions but thin for strike/crush/rake/spray/ambush/hurl — those six action types do not have strong natural psychic vocabulary and required stretched or weak candidates, honestly flagged above rather than forced as strong entries.
