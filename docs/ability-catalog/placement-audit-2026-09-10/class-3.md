# Placement audit, class 3 (2026-09-10)

The layer test: a name is ELEMENTAL if its word carries a medium, substance, or phenomenon that belongs to one element's productive list or its 5a mechanical fantasy (ray, halo, mist, mass, wither); it is NEUTRAL if it carries no medium at all (blow, aegis, presence). A NEUTRAL word's element placement claims a meaning it lacks and is UNSOUND there; an ELEMENTAL word's neutral placement is UNSOUND because it is not neutral. Duplication across cells is never itself a reason; every verdict below rests on the word's medium (or lack of one) and the action definition of the cell it sits in, not on the fact that it also sits somewhere else.
