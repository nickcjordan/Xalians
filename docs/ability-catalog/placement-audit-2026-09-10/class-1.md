# Placement audit, class 1 (2026-09-10)

Each row judges one element/action placement against two tests: does the element's 5a mechanical fantasy or its step0 productive-word list give this name's words that element's meaning, and does the action's registry definition support what the name describes. Duplication across elements is never a reason for UNSOUND; a name sitting in two sound placements is expected under the struck rule. Several verdicts below reverse the struck DEDUPE-LEDGER's dispositions because the losing element's own step0 file turned out to list the word as productive (ash and vapor in ghost, overload and searing in light, static and searing in ice, pressure/vacuum/momentum in both dark and air), which the ledger's "no medium" reasoning had missed.

- Overload family in light (Press/Punch/Push/Slam/Strike): light's own step0 confirms "overload" as productive, reversing the struck ledger's exclusive-electric claim; worth a second look since it changes five placements at once.
