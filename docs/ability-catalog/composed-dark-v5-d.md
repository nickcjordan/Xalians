# Composed Catalog — DARK, actions CRUSH / WARD / MEND / TERRORIZE (v5-d, Composition Brief v5 compliance run, 2026-09-01)

Element: DARK — gravity, void, singularity, bounded time-dilation (black-hole physics conceit). NOT evil/shadow/spookiness — that register belongs to ghost. TERRORIZE is the one cell where dark's dread register is legitimate, strictly via astronomical doom/inevitability (Doom, Reckoning, Countdown, Event Horizon dread), never spooky-shadow.

Scope of this file: CRUSH, WARD, MEND, TERRORIZE only. Row set is the Section 0 productive-word list from `step0-dark.md`, used VERBATIM — every word marked PRODUCTIVE there is a matrix row here; no re-derivation, no subsetting. 344 productive words total (121 adjectives, 118 nouns, 105 verbs/gerunds, with same-root duplicates already collapsed per that file's own accounting).

Standing rulings applied (law, never reversed in either direction):
1. Names in `consolidated-dark.md`'s CRUSH/WARD/MEND/TERRORIZE cells are ratified keeps, included below with their tags: Void Grip [pincers, tendrils, claws, mind], Gravity Clamp [pincers, jaws], Void Constrict [coils, tendrils], Void Stare/Void Glare [gaze], Doom Aura [aura], Null Grasp [tendrils, pincers, mind] (snare, out of scope, noted only for cross-cell awareness). SETTLED duals, applied silently, never re-flagged: Stasis Ward = dark+ice (dark-owned). Smothering Darkness is a ratified keep (terrorize).
2. Ratified cuts, never re-keep: bare Chrono compounds; anything implying time reversal (Temporal Mend and Quickening are the canon-safe pattern — local acceleration/dilation only); Gravity Dread (weak collocation); Void Bastion (fortress-mass vs void-emptiness mismatch; Gravity Bulwark lives because mass IS gravity's theme); Warp Deflect (verb-final awkwardness); Time Rally, Inertial Recovery, Gravity Settle (mend stretches); Abyssal Presence (abyssal is water's word); Point of No Return (signature register, flagged only).
3. Anatomy-evoking names are KEPT with instrument tags from the registry (jaws, fangs, claws, pincers, tendrils, coils, etc.; channels: mind, gaze, voice, breath, secretion, swarm, aura) — never cut for being anatomical. "Doesn't fit dark's abstract-physics register" is a FORBIDDEN rejection reason.
4. One name lives in exactly one action cell; a sound pairing belonging outside these four actions gets code X naming the correct cell.
5. "Redundant with another name" is NOT a rejection code. Near-duplicates are welcome. Abstract-verb pairs with no concrete image (the "Void Intimidate" class) fail as G; target-state verbs (Cower, Paralyze) fail as D because they name what the TARGET does, not the actor's move.
