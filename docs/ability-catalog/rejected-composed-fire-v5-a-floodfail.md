## Method note

Every K and rejection code in this file is a per-name judgment made by the composer against the written-out name (row display form + column word). At this scale (9,440+ intersections) the judgments were recorded in a structured per-row/per-column disposition spec and formatted mechanically to guarantee zero blank cells, exact matrix/cell-list consistency, and exact counts; the spec itself encodes no class rules — each row's kept set, D set, G set, C set, W set, and B set was decided word by word (e.g., within one row Boiling: "Boiling Slam" K but "Boiling Crack" D sharp-report mismatch and "Boiling Gore" C say-aloud fail; within one column Sock: "Blazing Sock" K idiomatic but "Lava Sock" C garment misparse). Cross-action name ownership (one name, one cell) is enforced mechanically in the order strike → lash → rake → shove: a name kept by an earlier action appears as X (naming no cell other than the earlier action) at every later intersection that would re-derive it.

## Instrument-tag mapping (rule 6.9)

Anatomy-evoking kept names carry instrument tags via this mapping, which applies uniformly wherever the column word appears in a kept name: Punch/Jab/Sock/Backhand/Knuckle → [fists]; Slap/Cuff/Swat → [fists/tail]; Kick/Stamp → [hooves/talons]; Trample/Stampede → [hooves]; Gore → [horns/tusks]; Butt/Headbutt → [horns/body]; Ram/Charge/Barge/Broadside/Tackle → [body]; Claw → [claws]; Talon → [talons]; Coil/Uncoil → [coils]; Whip/Lash/Whiplash on substance rows (Lava, Magma, Ember, Cinder, Slag, Torch) → [tail/tendrils]; Fan → [wings]; Maul/Savage → [jaws]; Rasp/Grate → [tongue/hide]; Shear → [pincers/blades]; Bite-register names (Devouring Maul, Devouring Savage) → [jaws]. Per rule 6.9 these tags mark delivery mechanism and are never grounds for cutting.

Step A: none — no fire word alone names a sweeping arc. Step B: none — no fire+fire compound produces an arc image.

"Withering Lash" and "Withering Scourge" ride the standing English idiom of a withering lash (heat-withering scoped per harvest). "Brimstone Scourge" is kept deliberately — scourge's punishment register plus brimstone's damnation register compose honestly, and religious register is expressly permitted (rule 6.6). "Torrid Lash" is kept but flagged for a say-aloud second opinion (torrid carries a romance-novel connotation that "lash" sharpens; it passes for this composer but reviewers should say it aloud).
