## 5. Excluded as other-domain / borrowed

**Excluded as other-domain:**
- Wormhole, singularity, entropy, event horizon, black hole, gravity well — gravity/time domain, not ghost
- Time warp, temporal rift, chronal — time domain
- Telepathy, hypnosis, mind control, psychic, clairvoyance, precognition — psychic/mind domain
- Soul (as standalone noun for names) — kept "soul sap" as a light compound but avoided leaning heavily on "soul" as it edges toward psychic/spiritual-mind domain in some contexts; used sparingly
- Necromancy, undead, zombie, lich — these lean into a broader "death magic" or fantasy-class domain rather than pure incorporeality/dread; excluded as too specific to a different subgenre framing
- Purgatory, limbo, afterlife, underworld, netherworld — kept as nouns (place vocabulary) but excluded from ability names since they carry religious afterlife-doctrine implications beyond abstract terms like dirge/requiem
- Reaper, Grim Reaper — excluded as borrowed/overused iconography rather than natural vocabulary
- Poltergeist-based names using "throw" mechanics reading as telekinesis — excluded telekinetic-sounding names (e.g. "Object Fling") as psychic-domain crossover

**Excluded as borrowed (recognized existing game move names or too-close variants):**
- Shadow Ball — classic monster-game move name
- Shadow Claw — classic monster-game move name
- Shadow Sneak — classic monster-game move name
- Shadow Punch — classic monster-game move name
- Night Shade — classic monster-game move name
- Ominous Wind — classic monster-game move name
- Phantom Force — classic monster-game move name
- Spite — classic monster-game move name (kept generic "curse"/"hex" vocabulary instead)
- Curse (as a standalone single-word move name) — too close to a well-known existing move name; used only as verb/noun in vocabulary sections and folded into longer compounds elsewhere

## Notes on richness

The field is exceptionally rich across all 16 action types — funerary/grave imagery (grave, shroud, cairn, ash, tomb) and specter vocabulary (wraith, spectral, phantom, banshee) combine productively to cover strike/lash/crush/rake cleanly. Drain and terrorize are the strongest categories, matching the element's dread/vitality-leech identity. Hurl and spray lean on the grave-dust/ash sub-register since ghost has no natural "mass" object otherwise — this sub-field is thinner than the others but still workable. Beam is serviceable but slightly forced (ghost is not naturally a "focused line" element); "chill ray" and "deathlight" are the strongest of a shorter list. Ward and mend both draw successfully on the shroud/veil protective imagery and the funerary "blessing/rest" register.
