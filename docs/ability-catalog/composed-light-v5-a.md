Assignment scope: LIGHT element, actions STRIKE, LASH, RAKE, SHOVE only. Follows COMPOSITION-BRIEF v5. Row set is the verbatim productive-word list from `step0-light.md` (301 productive words: 89 adjectives, 127 nouns, 85 verbs). Inputs: `harvest-light.md`, `harvest-action-strike.md`, `harvest-action-lash.md`, `harvest-action-rake.md`, `harvest-action-shove.md`.

Element canon applied throughout: LIGHT = illumination, radiance, prisms/refraction, solar power. Fire's heat-burning words (blaze-as-burning, sear-as-scorch, ignite-as-combust) are excluded from light's strike/rake/shove sense whenever the specific pairing reads as burning rather than optical force; kept where the pairing reads as intensity/flash. Concussive/hard-light framing is used for strike (beam-as-lance belongs to BEAM's turf per assignment, so "beam" + strike-verbs favor impact framing — hard-light slam, flash-force — over piercing-lance framing, which is reserved for BEAM). Shove via radiation pressure/photon pressure is composed where the definitions support it (surge, overload, corona, flare, flood, wash, radiance pressure framing).
