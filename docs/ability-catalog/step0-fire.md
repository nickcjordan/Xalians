# Step 0 — Productive-Word List — FIRE

Source: harvest-fire.md sections 1-3 (Adjectives, Nouns, Verbs/Gerunds). Per Composition Brief v5 Section 4 Step 0: every noun/adjective/verb concept classified PRODUCTIVE or NON-PRODUCTIVE. Only grammatical/formal reasons justify non-productive status — a multi-word phrase that cannot compose to 2 words, a bare combining form, or a word that cannot grammatically front/follow a partner word. Register, tone, theme, and abstractness are never exclusion reasons. Same-root duplicates across sections are collapsed to one row with a note. Other-element boundary words are flagged, not excluded, per element canon (never electric, never light-as-illumination).

This is the shared verbatim row set for the four downstream composers (strike/lash/crush/rake/shove/drain/ambush/beam/hurl/spray/burst/cloud/snare/ward/mend/terrorize sweeps are performed separately by each composer against this list).
