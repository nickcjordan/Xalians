# Composed Catalog — FIRE, actions DRAIN / AMBUSH / BEAM / HURL (v5-b, Composition Brief v5 compliance run, 2026-09-01)

Element: FIRE — combustion, heat, flame, ash, and the magma/volcanic register. Homeworld Magmuth is a volcanic hellworld, so magma/lava/molten words are fire-owned; where a magma/lava/slag word could honestly double as rock (structural, solid-mineral usage rather than heat/flow usage), it is flagged as a dual candidate but KEPT in fire's cells per element canon's explicit ruling that fire owns the magma/volcanic register. Never electric (spark-family words are excluded; none arose from the Step 0 lexicon, and none surfaced during this run's Step C sweeps either). Never light-as-illumination (Glowing/Incandescent are heat-radiance only; each composed name using them is judged individually for whether it reads as illumination rather than combustion heat). Fire's DRAIN register is anchored on heat drawing out moisture and vitality — parching, withering-by-heat, evaporating, scorching-dry — not tidal pulling or siphoning-through-a-tube (those are water/psychic mechanisms); fire's mechanical-suction words (siphon-style) mostly fail definition-honesty for this reason, while contact/blister/sear-style words cross more naturally into touch/grasp-style compositions.

Scope: this run composes only the four assigned actions — DRAIN, AMBUSH, BEAM, HURL. No prior consolidated fire file exists for these four actions; this is a fresh Step A/B/C sweep from scratch, held to the same rigor bar as the water v5-b model file (format/rigor model only — the water file's occasional "X redundant" treatment of same-cell near-duplicates is NOT followed; per this run's standing ruling 6, near-duplicates within the same cell are both kept, never one cut as redundant).

Standing rulings applied as law (this run's assignment):
1. No prior fire file to preserve; harvest candidate-name lists are a starting point only.
2. Hard cut classes: borrowed creature-game names (Fire Blast/Flamethrower class — flag and keep if unsure, never silently cut); real-world weapons/modern-tech idiom (Napalm, ordnance compounds — "Incendiary" the adjective is usable, napalm/ordnance-branded compounds are not); Earth fauna/flora; bare pyro- combining forms (already excluded at Step 0); canon rule 11 (no time reversal, teleportation, life creation, permanent transformation, puppeting, true invisibility).
3. Water/other-element words never serve fire; Steam is fire/water boundary, flagged dual if it surfaces, never owned outright.
4. Anatomy-evoking names are KEPT with instrument/channel tags from the brief's registry; fire breath names take [breath].
5. One name, one cell; out-of-scope sound pairings that fit a different action are coded X, naming the correct cell even outside this run's scope.
6. "Redundant" is NOT a rejection code. Near-duplicates within the SAME cell are both kept. X is only for cross-action duplication (a name already kept in a DIFFERENT action's cell).

## Summary

This run composed FIRE's four assigned actions (DRAIN, AMBUSH, BEAM, HURL) from scratch per Composition Brief v5 Section 4's mechanical algorithm, with no prior fire file to preserve or reverse. DRAIN was disciplined by fire canon's explicit anchor (heat draws out moisture/vitality via parching/withering, not tube-siphoning): mechanical-suction words like Siphon and Tube-Extract failed definition-honesty against nearly every fire word, while Sap/Tap/Drain/Wither/Wick/Pull/Draw survived widely, and the drain register's own generic root-words (Burning, Fiery, Ablaze) were correctly cut as tautologies rather than kept as lazy padding. AMBUSH proved the richest cell, splitting cleanly into a kinetic charge/rush/blitz/onrush sub-field (blaze, cinder, scorch, volcanic, wildfire, firestorm family) and a stealth sub-field genuinely earned by the smoldering/smolder root (a low, hidden, patient heat is a strong natural match for stalk/prowl/lurk/skulk/slink), while static-structure fire nouns (furnace, forge, kiln, bonfire, pyre) were consistently and correctly rejected across all four actions as immobile and therefore incapable of any of the actions' inherently active verbs. BEAM was the thinnest cell by honest necessity, exactly as the harvest itself flagged — heat does not collimate — but still yielded 49 names by leaning on the loose-geometry beam-family words (Stream, Jet, Column, Pillar) against the volcanic-flow register, plus the sharper Lance/Ray/Beam family against Ember/Cinder/Scorch/Flame, with every Glowing/Incandescent candidate correctly failing the individual illumination-vs-heat test rather than being blanket-kept or blanket-cut. HURL was the widest cell, combining the siege/weather-metaphor synonym register (barrage, volley, rain, hail, shower) with fire's own volcanic-ejecta nouns (ash, cinder, slag, brimstone, magma) to produce natural, real-phenomenon compounds (Ash Shower, Brimstone Rain) alongside the plain-tier action-word compounds the brief explicitly protects (Molten Hurl, Magma Hurl). Magma/lava/slag/volcanic-vein names were consistently flagged dual-rock-candidate but kept in fire per canon; Fireball and Torch Beam were flagged borrowed/modern-tech-boundary suspicions and kept rather than silently cut, per the standing "when in doubt, keep and flag" rule. No name was cut as "redundant" within its own cell — every near-duplicate surfaced during Step C (Ember Rain/Ember Hail, Magma Hurl/Molten Lob, Ash Shower/Ash Rain, Boiling Rain/Scalding Rain, and others) was retained per this run's ruling 6, a deliberately stricter reading than the water v5-b format model's occasional same-cell "X redundant" treatment.
