# Draft Consolidated Catalog — SAND, all 16 actions (v5, pending Fable audit)

## Pipeline

This file is the mechanical merge of a four-way composition fan-out plus a restoration sweep, in three stages:

1. **Composition fan-out.** Four composer agents each handled 4 of the 16 action cells for the sand element: `composed-sand-v5-a.md` (STRIKE, LASH, RAKE, SHOVE), `composed-sand-v5-b.md` (DRAIN, AMBUSH, BEAM, HURL), `composed-sand-v5-c.md` (SPRAY, BURST, CLOUD, SNARE), `composed-sand-v5-d.md` (CRUSH, WARD, MEND, TERRORIZE). Each ran the full Composition Brief v5 Section 9.5 synonym cross for its four actions and produced a final "kept" flat list per cell, along with per-file Flags and Lexicon Disposition Table sections.
2. **Mechanical merge.** This document assembles those 16 flat kept-lists into one catalog. The four independent composer files produced a substantial number of identical strings kept in two different cells (the "one name lives in one cell, chosen by definition" rule the four independent runs could not catch against each other since they never saw one another's output) — every one of these is resolved below under "Cross-cell resolutions," by definition, not by whichever file happened to list it first.
3. **Restoration sweep.** `redundancy-rejections-sand.txt` extracted every line any of the four files rejected specifically for a stated reason mentioning redundancy — only 3 lines total for this element (sand's composers overwhelmingly used T/D/G/X codes rather than "redundant" as a stated reason, and one composer even self-corrected a redundancy-based cut back to a keep before this sweep began). Each of the 3 lines is individually dispositioned below; none produced a restoration, because none was an actual cut name — see the Restoration Ledger.

**This file is pending a Fable (human-facing agent) audit pass before being finalized.** Nothing here should be treated as final canon until that review lands — in particular the cross-cell collisions resolved below (STRIKE/SHOVE impact-vs-displacement verbs, WARD/CLOUD covering vocabulary, RAKE/SPRAY/HURL projectile vocabulary, SPRAY/BEAM jet vocabulary, SPRAY/CLOUD lingering-vs-ejection vocabulary, SPRAY/BURST "Sand Blast," AMBUSH/BURST "Sand Burst," LASH/RAKE edged-repetition vocabulary, LASH/SNARE "Grit Coil," RAKE/DRAIN "Attrition," STRIKE/WARD/CRUSH "Duricrust"/"Hardpan") were resolved by this merge pass using judgment calls the auditor should specifically re-check.
