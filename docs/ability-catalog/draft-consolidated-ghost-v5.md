# GHOST — Consolidated Draft (v5)

Merger of `composed-ghost-v5-a.md` (STRIKE/LASH/RAKE/SHOVE), `composed-ghost-v5-b.md` (DRAIN/AMBUSH/BEAM/HURL), `composed-ghost-v5-c.md` (SPRAY/BURST/CLOUD/SNARE), and `composed-ghost-v5-d.md` (CRUSH/WARD/MEND/TERRORIZE), per COMPOSITION-BRIEF v5 and the consolidate-element skill's merge + restoration-sweep step. All 16 cells are written out inline as flat name lists — never pointers back to the source files. Restored names (from `redundancy-rejections-ghost.txt`, disposition per the six-clause restoration policy) are marked **°**. Fold-in names (matrix K's proven in a composer's own matrix but absent from that composer's flat cell list, per the mandate to trust itemized lists/matrices over count labels) are marked **⁺**.

Element canon: GHOST = spectral, incorporeal, haunting register (homeworld Phantiri, the Dreadscape). Ghost owns the spooky-shadow/haunting register; DARK owns gravity/void physics plus its ratified Doom/Reckoning/Eclipsing Presence/Smothering Darkness/Void Dread fate-terrorize register, the Umbral Pall/Ward/Shroud family, and the Vortex/Stasis/Supernova/Tidal families — none of that is re-derived here. Canon bans respected throughout: nothing implying literal possession/body-control, true invisibility, or time reversal survives as a mechanic-claim name; descriptive spectral senses (a strike that "vanishes" into view, a grip "unseen" until it lands) are fine and are flagged inline wherever a composer flagged them. Chemical boundary: ghost's decay/miasma-register names carry a (dual-candidate: chemical) note wherever a composer flagged one.
