# Composed Rock — Actions: CRUSH, WARD, MEND, TERRORIZE (v5-d)

Per Composition Brief v5. Row set is the verbatim productive-word list from `step0-rock.md` (313 PRODUCTIVE rows: 102 adjectives, 127 nouns, 84 verbs/gerunds — same-headword duplicate senses across sections, e.g. Buttress noun/verb, Quarry noun/verb, Dress adjective/verb, Mortar noun/verb, Armor noun/verb, Plate/Shell/Carapace noun/verb, Fracture/Fissure/Crack/Cleave adjective/verb, Quake noun/verb, Tower adjective/verb, Ground/Root/Plant verb-only senses, collapse into one row each in this composer's working set the same way `step0-rock.md` itself collapses "craggy-faced" into "craggy" — yielding 303 distinct headword rows carried into the crosses below; no word or sense is dropped, only same-spelling repeats across grammatical categories are counted once).

Element canon: ROCK = stone, earth-mass, seismic force, asteroids (Stonera, per `planets.json`). CRUSH is rock's deepest signature register — grinding stone, tectonic pressure — composed from bedrock/tectonic/granite-class words plus pressure verbs, deliberately NOT reusing the millstone/mechanical-device register that belongs to Dark's Millstone-class names. WARD draws on stone walls and bedrock bulwarks. MEND is honestly thin (mineral restoration, setting-like-stone) and stays thin rather than being padded. TERRORIZE is the looming cliff, the groan of shifting earth, the coming quake.

Standing rulings (law, not reversible in either direction):
- No borrowed names (Rock Polish, Wide Guard class, or any other exact match to an existing creature-game move name) — flagged with code B, kept in the cell per brief Section 1/8 ("keep and flag"), never silently cut.
- No real weapons or modern tech.
- No bare litho-/geo- combining forms standalone or fronting (rule 6.7).
- Grip-family names (X Grip, X Clutch, X Grasp) belong to SNARE, not CRUSH — every such candidate is coded X-to-snare in the CRUSH matrix below and not placed in the CRUSH cell, even though the harvest's neutral-keeper list included some (Iron Grip, Crushing Grip, etc.) as crush-flavored; this assignment's ruling overrides that placement for ROCK's own compositions.
- Vise and Clamp names stay in CRUSH (explicitly carved out of the grip-family exclusion).
- Anatomy-evoking names (Vise, Talon, Jaw, Grip[if used in Snare], Clamp, Stare, Roar, etc.) are KEPT with instrument tags from the registry (rule 6.9) — never cut for being anatomical.
- One name lives in exactly one cell.
- "Redundant" / near-duplicate is never a valid rejection reason.
- Canon bans permanent transformation, time reversal, teleportation, creating life, puppeting, true invisibility (rule 6.11) — relevant mainly to MEND (no "undo damage entirely" framing) and to any name implying petrification-as-permanent-transformation-of-another-creature (Petrify/Petrifying names are kept as damage/fear-flavor only, never as "turns the target permanently to stone").
- Boulder, Rubble — reserved OUT of the shared neutral pools for rock; this composer places them directly (per `step0-rock.md`'s carried-forward ruling).
- Avalanche — ICE-owned; ROCK cross-references it in flags only, never claims ownership in a cell.
- Obsidian — fire-adjacent origin, kept productive as a rock-type mineral noun, cross-referenced to FIRE in flags.
- Mineral, Quartz, Feldspar, Mica, Granite, Basalt, Gemstone — flagged as touching METAL's ore/mineral boundary; kept rock-owned per harvest's explicit note (raw/unrefined stone, not smelted/forged).
- Sandstone — flagged as sharing SAND's namespace; kept rock-owned per harvest note (rock-type sense).
