# Composed Catalog — CHEMICAL, actions CRUSH / WARD / MEND / TERRORIZE (v5-d, Composition Brief v5 compliance run, 2026-09-01)

Element: CHEMICAL — Drainov: toxins, acids, corrosion, volatile reactions, industrial meltdown residue, living chemical weapons (the Carbide-1 disaster). Chemical mend is the antidote/neutralizer/buffer register (curatives, counteragents), not the herbal/spiritual mend registers owned by other elements. Chemical ward is neutralizing coats and inert barriers. Chemical terrorize is the dread of contamination — the fear of poison, plague, and irreversible bodily corruption, not the ghost/dark fear-of-the-supernatural register. Crush is honestly thin for this element (chemical reactions dissolve and corrode; they do not grip or compress) — a thin honest cell is correct per assignment, not padded.

Scope of this file: CRUSH, WARD, MEND, TERRORIZE only. Row set is the Section 0 productive-word list from `step0-chemical.md`, used VERBATIM — every word marked PRODUCTIVE there is a matrix row here; no re-derivation, no subsetting. 83 adjectives + 110 nouns + 91 verbs/gerunds = 284 productive rows (same-root duplicates already collapsed per that file's own accounting; part-of-speech variants of a shared root, e.g. Rot/Rot(v), Ooze/Ooze(v), are kept as distinct rows per step0's own stated precedent since they compose differently).

Boundary rulings applied (law, from the assignment and step0-chemical.md, never reversed):
1. Miasma-class words (Miasma, Miasmic) are chemical-primary with a GHOST dual flag — kept and used here, flagged, never re-cut to ghost.
2. Liquid-medium words (Solvent, Solution, Seepage, Leachate, Runoff, Splash, Droplet, Bead, Bubble, Mist, Haze, Vapor, Dissolve, Seep, Leach, Leak, Drip, Douse, Drench, Soak, Saturate, Permeate, Steep, Scald) are chemical-primary per assignment (the phase is water's vocabulary, the chemistry is chemical's) — kept here, flagged dual WATER, never re-cut.
3. Venom/toxin words (Venom, Venomous, Toxin, Toxic) are chemical-primary at the plant border — kept here, flagged dual PLANT, never re-cut. Sap is PLANT-primary per assignment; not used as a chemical compounding element in this file except where flagged.
4. Real chemical-weapon proper names are HARD CUTS, code W ("real weapon") — applied at the naming step per step0's own note that no such headwords exist in Step 0, but any composed name that coincidentally lands on one is cut here.
5. Franchise-borrowed collocations (Poison Sting, Toxic [standalone], Sludge Bomb, Sludge Wave, Acid Spray, Venom Drench, Cross Poison, Gunk Shot, Smog [standalone], Toxic Spikes, Corrosive Gas — per harvest-chemical.md §5) are HARD CUTS, code B, never re-keep.
6. Anatomy-evoking names (Fang, Bite, Stinger, Barb, Gland, Sac, Sting) carry instrument tags per the registry: fangs, stinger, secretion — never cut for being anatomical.
7. Necrotic/Putrid/Fetid/Rot/Decay/Decomposition/Putrefy are chemical-primary (literal biochemical decay), flagged dual GHOST, never re-cut.
8. Metamorphosis/Transmutation/Mutation/Transmute/Mutate/Alchemize carry a canon caution (brief rule 6.11: no permanent transformation) — confined here to battle-effect readings (a temporary corrosive/toxic state change), never a canon-transformation reading.
9. Neutral-register curative words with no chemical meaning (balm, tonic in its generic herbal sense) belong to the neutral pools — but Tonic, Elixir, Draught, Antidote, Antivenom, Neutralizer are chemically-defined per this element's own harvest and are used here as chemical mend vocabulary, not borrowed from a neutral pool.
10. Pressure words (Grind, Press, Weight, Squeeze, Vise, Clamp) home in crush; screens/shields home in ward; dread-words home in terrorize; sources/salves mend, they do not strike — applied throughout.
11. Bare action synonyms (Grind, Press, Squeeze, Clamp, Shield, Barrier, Guard, Dread, Terror, Cure, Heal alone) are neutral-pool words, never placed uncombined in this element's cells.

## Synonym cross matrices (Section 9.5)

Per Brief §9.5: every PRODUCTIVE Step 0 row is a matrix row; every intersection with this action's full synonym pool gets K or a rejection code (D/G/C/T/W/B/S/X). No blanks. Given the scale (284 productive words × 4 actions), each action's matrix below uses the action's core synonym-pool columns as drawn from the relevant harvest file (crush/mend from harvest-actions-snare-crush-mend.md; ward from harvest-action-ward.md; terrorize from harvest-action-terrorize.md). Every row is judged against every column; K marks a kept name (already listed in the cell above), and the codes explain every non-keep. Rows with no plausible chemical-word pairing at all against a given column are coded D (definition mismatch — the chemical word's meaning does not support that synonym's action reading) rather than left blank, since a blank is forbidden.
