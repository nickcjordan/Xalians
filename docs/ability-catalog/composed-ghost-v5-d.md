# Ghost Element — Composition (v5-d): CRUSH, WARD, MEND, TERRORIZE

Element: GHOST — spectral/incorporeal/haunting register (Phantiri, the Dreadscape). Ghost owns the spooky-shadow/haunting register; DARK owns gravity/void physics and the ratified Umbral Pall/Umbral Ward/Umbral Shroud compounds, plus its ratified terrorize cell (Doom, Reckoning, Eclipsing Presence, Smothering Darkness, and the rest of its fate/void register — never re-owned here). Actions assigned: CRUSH, WARD, MEND, TERRORIZE only. Row set is the productive-word list from `step0-ghost.md` verbatim (collapsed duplicate roots counted once per that file's own collapse notes), matching the row set already used in `composed-ghost-v5-a.md`.

Element canon for this pass: CRUSH is honestly thin — a spectral grip has little mass, so this cell covers only the dread-weight/grip register (cold hands closing, a weight of dread bearing down), never literal mechanical crushing (no vise/press/millstone machinery — that is DARK's and ROCK's). WARD covers wards against and by spirits; the religious/ritual register is explicitly allowed (blessing, benediction, consecration, exorcism). MEND is limited to soothing the spirit and laying it to rest — nothing implying creating or restoring life/flesh. TERRORIZE is ghost's deepest signature register and is composed exhaustively — this is where the haunting register lives in full (wails, visages, dread presences, grave chills) — while never re-deriving DARK's kept fate/void names.

- **Anatomy tags:** grip/clutch/clasp/clench/grasp names in CRUSH and voice-register names in TERRORIZE (wail, howl, shriek, moan, groan, keen, whisper, murmur, cackle, rattle, glare, stare, gaze, aura) all carry registry tags per rule 6.9 — [hands], [claws], [coils], [tendrils], [voice], [gaze], [aura], [body] as appropriate.
- **Signature register:** no names in this pass were judged grander than the 2-plain-word catalog tier; none flagged to a signature pool.
- **Dual-element candidate:** "Smothering Embrace" (CRUSH) borders CHEMICAL's suffocating-vapor register per step0's boundary note on "smother" — kept here in the cloth/spectral-embrace sense (a shroud closing around the target), not toxic gas; flagged for cross-check.
