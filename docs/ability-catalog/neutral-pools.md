# Medium-Neutral Name Pools — Stage 2b (2026-09-01)

Purpose: build the NEUTRAL pool per action — names any element can draw because they carry no elemental meaning. Source: the 16 action harvest files (each action's own noun/verb/synonym field), read through the COMPOSITION-BRIEF v3 lens (element composition is a *separate* downstream pass; this file only pools the bare action-synonym layer plus natural neutral compounds already surfaced in each harvest's own "element-neutral candidate names" sections).

Method: for each action, walk its harvest lexicon and its own §3 "element-neutral candidate names" list. Keep only names/words that are (a) 1-2 words, (b) carry no elemental meaning (no medium, no substance, no phenomenon tied to one of the 14 elements), (c) not borrowed from an existing creature-collection game, (d) not a real weapon/military-modern term, (e) not Earth fauna/flora, (f) not modern-tech idiom, (g) not signature-register (mythic/grander-than-plain), (h) not unintentionally comedic. Anatomy-evoking names carry instrument tags from the brief's registry. Everything else is dispositioned to element or cut with a reason. One name lives in exactly one action's pool by definition, not vibes.
