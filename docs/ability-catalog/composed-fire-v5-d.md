- **Borrowed-name suspicion:** none identified in these four cells. (Fireball-type generic-fantasy risk, flagged in the source harvest, falls under HURL, not an assigned action here.)
- **Signature-register (moved out of cells, listed here only):** none generated — no name in these four cells' compositions rose to the grander multi-clause register the brief reserves for the signature pool (e.g., nothing on the order of "Point of No Return").
- **Rows sourced from harvest but not used as Step-0 catalog rows:** Hearth, Warmth, Wrath. These appear in the assignment's prose framing ("the hearth comforts") or in candidate lists within the four action-harvest files (Blazing Wrath, Kindled Wrath appear as plausible pairings) but are NOT rows in the Step 0 productive-word list handed down verbatim, and are not action-pool synonyms either.
