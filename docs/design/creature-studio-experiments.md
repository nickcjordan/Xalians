# Creature Studio: process experiment log

Nick, 2026-10-12: "All of this is still an experiment, so I want to make sure that you are tracking the decisions we make and whether or not that results in a better outcome so that we can iteratively adjust our process as we go."

Every process decision about how creatures get made is an experiment until evidence says otherwise. Each entry records what was decided, why, what outcome would show it worked, how that is measured, and, once there is evidence, the result and a verdict (keep, adjust, revert). This log is about the process; creature design rulings live in each creature's records.

## How the log is kept

- A new entry is added the day a process decision is made, with Nick's words when the decision is his.
- Results are filled in at three moments: when a stage closes, at each check-in where the evidence is new, and at the creature retro (end of Phase 1). A result cites numbers or images, not impressions.
- A verdict of adjust or revert creates a new entry for the replacement, linked both ways.
- At each creature retro, every open entry is reviewed and either given a result or explicitly carried to the next creature.
