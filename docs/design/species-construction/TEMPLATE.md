# Species construction brief template

Copy into `<species>/brief.md`, replace placeholders, and create the six-stage package using the Akinza package as a structural example. Do not copy Akinza's anatomy, decisions, approval text, hashes, or camera assumptions.

## Identity and evidence

Species key, source SVG and record paths; abstract source interpretation; preferred style and accepted corrections; stable part IDs. Distinguish observation, Nick's direction and proposed depth.

## Pose sets

Describe the expressive reference pose and proposed modeling pose separately. Define baseline and landmarks appropriate to this body plan. State the creature's left/right and how nominal cameras are named.

## Construction questions

List unresolved volumes, thickness, hidden surfaces and attachment relationships. For each, name the smallest useful study and the decision it will resolve. Do not invent numeric dimensions without labeling them provisional.

## Study queue and review

Each study: identifier, purpose, exact inputs, affected part IDs, pose, views, prompt path, provenance path, outputs, visual findings and next correction. Approval is null until Nick explicitly identifies accepted art. Record what the acceptance covers.

## Next unfinished action

Concrete executable action or exact review question, with the artifact to inspect. Link the shared work record.
