# Preserved Powerworks painted-art reference

Archived September 22, 2026 at Nick's request. Nick likes this treatment and wants it retained for future reference. It is set aside while a separate Blender creature animation and accompanying environment direction is explored. This is not the approved universal Xalians house style or a change to canonical creature anatomy.

- `originals/`: original generated PNGs for Graviclaw, Avilily (corrected talons), Crystorn, and Hippochamp.
- `sprites/`: exact deployed WebP copies of those four companions, five game-specific mechanical enemies, and the existing turbine-hall background. The environment is contextual reference, not a new approval.
- `checksums.json`: SHA-256 fingerprints at archival time.
- [Original implementation, prompts, and provenance](../../powerworks-composition-pass.md).

Working description: painterly, stylized 2.5D fantasy with industrial science-fiction details. Sculptural volumes, readable silhouettes, restrained painted texture, warm highlights, cool teal rim lighting. Teal and bronze machinery belongs to Powerworks rather than all planets.

Keep these copies independent of live game assets so future replacements do not erase this reference. The new toon/lined exploration must not inherit this style by default.
