Site chrome, proposed (square, with the chamfer for emphasis)

One design system for everything that is not a game in progress. Same room, same type, same frame we already have, with the terminal props removed: no tape, screws, hinges, clips, stamps, nameplates, fake readouts or in-world button copy. One neutral surface family, one accent, glass only where the content is live data, and the element hues as the only saturated color. Corners are square everywhere; the twelve pixel chamfer is reserved for the glass tier and the one primary key on a screen, so the cut marks what is live and what is next. Below: the navbar and home, a generator record, the encyclopedia with one featured component, and a settings form, all in the same system.

The three tiers

Site chromeEverything that reads, browses, configures or manages: navigation, home, account, encyclopedia, generator, every lobby and setup and results screen. One system, as above. Quiet, coherent, daily.
Featured componentsRicher pieces built inside the chrome from the same tokens and type: the galaxy map, a species plate with its element wash, a story reader, a stat chart. They give an area character without changing the site.
Immersive experiencesA game in progress: the duel board, the Reclamation match, the training minigames, Long Return. Entered deliberately, may replace the chrome, keeps the core (type scale, element hues, stat semantics, contrast floor), and always has a way back out.
What leavesTerminal objects and their props, fake readouts, in-world button copy, per-area typefaces, per-area accents. The world lives in the content. The interface stays quiet so the content can be loud.
