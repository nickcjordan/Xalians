## Borderline category calls

- **Vallerii -> people.** It is a race, not an individual, but the instructions reserve "xalians" for creature/race entries that are Xalians specifically. Vallerii are the (extinct) creators, not a Xalian species, so "people" reads truer than inventing a "races" bucket. Low-medium confidence; could argue for a dedicated non-Xalian-race category if the schema grows.
- **APEX -> xalians.** APEX is an AI, not a creature. It does not fit history/factions/people/places/technology/substances/phenomena cleanly either. Chose "xalians" only because APEX exists entirely inside the Xalian Generator ecosystem (built to regulate them, later turns on their creators) and has no better home in the given eight categories. This is the weakest call in the set — flagging for review; "technology" (it's engineered software) is the runner-up.
- **Battle Fee -> xalians.** Per the prompt's own explicit flag. It's a game-mechanic value assigned to Xalians, not a creature/race itself, but it is entirely about Xalians and has no natural technology/phenomena home. Judgment call, low-medium confidence.
- **Death Tide -> history.** Reads as a recurring biometeorological event/phenomenon on Poseidas, but its definition frames it as a named calamitous event ("a biometeorological event that occurs") parallel to Magmuth Massacre and Drainov Disaster rather than an ongoing atmospheric mechanic like Black Lightning or Bloodstorm. Placed in history as a "notable disaster-class event" rather than phenomena; reasonable alternate call is phenomena given it's not a single dated occurrence but a recurring semiannual event.
- **Bacillota Requiem -> substances.** Definition describes it as "the scientific name for the microorganism that produces Nightcap" — technically an organism, not a substance. No "biology/organisms" category exists among the eight, and it's inseparable from Nightcap in function, so substances was the closest fit over phenomena or technology.
- **Windsailor / Veridians -> factions.** Both read as demonyms/labor-culture groups (a profession-turned-culture, and a planet's population) rather than formal organizations like ECHELON or the Syndicate, but "factions" is still the best of the eight for named human(oid) collectives with a defined role.
- **Neph -> xalians.** Unambiguous (explicitly "specially engineered Xalians"), included here only to note it was considered against "technology" (they're an engineered tool) before settling on xalians since they are literally Xalians per the text.

## Notes on `related` extraction

Links were generated by a literal, case-insensitive scan for each OTHER entry's exact title text appearing inside a given entry's definition. This produced a few asymmetric or empty link lists that are expected, not bugs: e.g. "Xalian Generator" itself has no `related` entries (its own one-line definition never names another cataloged term), and "Magmuth" and "Stonera" likewise have empty `related` lists because their short definitions don't quote another entry's exact title.
