# Creature Studio lessons

One file per lesson (docs/design/creature-studio-reuse.md, "Lessons"): what it governs, when it applies, its status (current, superseded with reason, archived), its evidence, the creature and the date. A brief carries at most five lessons, chosen by the orchestrator; builders say which lessons shaped their method; a lesson no build cites across two creatures is archived at the creature retro. Process rules that became studio behavior are not repeated here.
