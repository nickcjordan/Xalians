# sheet-turnaround-one-image-first

- Governs: model sheet procedure
- Applies when: Generating a creature's turnaround
- Status: current
- Creature: hypnopet
- Date: 2026-10-13
- Evidence: Hypnopet B-tbyq (set aside), B-a27k (used); views B-gpi3, B-cuzk, B-y5ca, B-mjoe, B-euan

Draw all five turnaround views in one image first, then redraw each view large from that image. Image models keep one character consistent within a single picture far better than across separate generations. Check the one-image sheet against the description's must-haves before redrawing views from it (Hypnopet's first sheet had small hind legs, a too-saturated coat and faint tips; one corrected pass fixed them).
