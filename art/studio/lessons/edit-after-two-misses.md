# edit-after-two-misses

- Governs: image generation
- Applies when: An option set or sheet image that missed twice
- Status: current
- Creature: hypnopet
- Date: 2026-10-13
- Evidence: Hypnopet palette rounds 1 to 3; picked B-4fxg

After two regenerations miss on the same element, stop drawing new sets: edit the closest image directly and change only the named colors or shapes. Hypnopet's palette missed twice (an in-between coat, then pink inner ears) and the third pass, three targeted edits of one image, was picked.
