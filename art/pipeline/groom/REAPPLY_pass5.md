# Luceras pass 5, B-7qgf

The groom is generated by `build_groom.py` and `parameters.json`. The approved sculpt is read only. Original mesh positions, vertex order, topology, eyes and claws are preserved. No UV map is added. The solved pass3 atlas is projected from the game mesh with barycentric UV sampling, as recorded in `pattern_transfer.json`.

Run on a copy of the approved sculpt, or an identically topologized rig in rest pose. Keep the object name `luceras_blockout`, its local coordinates, and original vertex indices. Existing armature and deformation-only modifiers are supported. The script rejects evaluated topology changes. The game pass3 `surface.blend`, `basecolor_2048.png`, and repository `roster/lookdev.py` remain read-only dependencies.

`deliver_on_build=true` produces all final views and a separate bent-pose proof. Set it false for a preview build and choose `--views tail_plume,toes,side,sprite`. `--mode render` rerenders selected views from the output `groom.blend`; `--mode deform` generates only the pose proof.

Every strand stores its root triangle indices, barycentric weights and point offsets in an orthonormal triangle frame. A Geometry Nodes modifier samples evaluated body vertices and reconstructs the hair. This is the no-UV equivalent of Deform Curves on Surface. It follows surface position and rotation without stretching the strand under triangle shear. Children are baked editable hair curves. Regenerate the script after changing guide authoring; manual guide edits do not automatically regenerate children.

The inherited body generator draws the full original material arrays before filtering local replacements. The final body coordinate, root-color, gain and strand-tone fingerprints are compared with an independent original-generator run. Local edits cover plume, toes and eyelids only. Toe creases use short fur breaks, claw-directed combing, skin values and a shallow shader bump, not mesh displacement.

Each major plume tuft has a name, station, color, length, width, angle and density in the parameters. Station 0 is y0.580m and station 1 is y0.695m. Dark tufts form the outer crest; shorter white locks form the inner band. A separate short white undercoat connects their roots along the curl. The three pale base locks that read as loops were removed, leaving 25 major tufts. The plume uses 25 points per strand; inherited body strands retain 9. The upper eyelid uses a mildly flattened arc while leaving the amber iris and horizontal pupil open.

The neutral lights, ground and cameras are in `SWAPPABLE neutral studio`. Replace that collection and the world to change lighting. Cycles uses CPU with six threads. The required `gpu` slot is still used. The monitor records sampled whole-device GPU memory separately; it is not an exact transient allocation peak. No Cycles GPU rendering allocations are made.

Shipping sprite and portrait sources are saved as `render_sprite_4x.png` at 768px and `render_portrait_4x.png` at 2048px. Depth of field is disabled. Both use 128 maximum samples, Blackman-Harris pixel-filter width 1.0 and no denoising. `compose_proof.py` uses existing Pillow to reduce them with Lanczos to 192px and 512px and makes the comparison images, without sharpening or recoloring. Its output path is the delivered pass5 directory; update `O` for a different output directory. The Blender groom itself requires only its script and parameters.

Frame times include render synchronization and PNG writing, but exclude build time and slot wait. Resize time is measured separately. All final frame records carry the selected build's script and parameter hashes. `deformation_proof.blend` contains a temporary armature bending one hind leg 18 degrees and the tail 12 degrees; the main groom remains in rest pose.
