## Method (the same constraint for both streams)

Work in Blender 5.2.2 (WSL: `wsl -d Ubuntu -- /home/njord/.local/opt/blender-5.2.2-linux-x64/blender -b --factory-startup --python-exit-code 1 --python <script> -- <args>`; put --python-exit-code before --python; LF line endings in scripts). Start from the base file. The pipeline rule (roster layer, decision 12): soft look-driven forms come from reconstruction, not hand-placed masses; rigid and precise forms are authored. For the torso that means: the trunk's volume comes from the body reconstruction already in the base, refined by sampling the raw reconstruction where the blockout smoothed it, and by brush work against the clay views for the landmarks a shaved body shows (sternum keel, scapula plates, last rib, belly tuck, hip points, spine groove). Do not build the trunk from primitives or metaballs. The result must be one closed manifold for the whole body (the head, horns, eyes and whiskers stay as they are: separate rigid objects where they already are). Keep the whole creature under 400K triangles.

Every Blender launch goes through the machine slot lock, which queues you behind the other stream: from Windows `python C:\dev\src\xalians-creature-pipeline\art\pipeline\slot\slot.py run blender -- <command>`, from WSL `python3 /mnt/c/dev/src/xalians-creature-pipeline/art/pipeline/slot/slot.py run blender -- <command>`, add `--wait 1800` when you must wait; a GPU job uses `run gpu` the same way.
